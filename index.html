What is Promethee-Selenium?

Promethee-Selenium is an industrial-grade web automation framework built in Python. It features a Page Object Model (POM) native architecture and provides stability up to 40 times more reliable than standard Selenium scripts. If you need speed, developer productivity, and native AI Agent integrations, you will love Promethee.

from promethee_selenium import PrometheeTest

class TestExample(PrometheeTest):
    def test_login(self):
        self.go_to('https://example.com')
        self.click_element('button', 'Login')
        self.assert_url('/dashboard')
Core Advantages

Fast

Smart waiting and parallel execution. Near-zero reflection overhead. Predictable automation performance across all browsers.

Page Object Model

Native Page Object Model support. Standardize your testing architecture cleanly right from the start.

Crash-free

Catch panics, handle alerts, recover browser contexts automatically. Your testing runs are robust and always complete.

Bilingual by Design

Full CLI interactions, detailed exceptions, and interactive documentation natively available in English and French.

Built for AI agents

Model Context Protocol (MCP) server support, structured accessibility tree context, and token-efficient CLI for agent interactions.

Visual Trace Viewer

Explore interactive DOM snapshots, network requests, console logs, and step-by-step executions after every test run.

Interactive CLI

Bootstrap a production-ready POM project structure (with configuration, sample pages, and tests) in seconds.

VS Code Extension

Run, debug, and record your browser tests directly from your IDE with modern debugger integration.

Any browser. Any platform.

Chromium, Firefox, and WebKit on Linux, macOS, and Windows. Headless and headed. Also available for Python, .NET, and Java.
